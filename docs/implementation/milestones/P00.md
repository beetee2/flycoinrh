## Use the prototype

From this checkout, run `make serve-lab` (equivalently
`.venv/bin/python -m flytrap.lab`). Open **http://127.0.0.1:8766/lab**.
The local server was left running for human use. If starting a fresh process,
stop an existing instance using that port first. The root URL redirects to
`/lab`. Built UI assets are present; rebuild after source edits with
`npm --prefix web run build`.

Choose presets or draw with pointer, touch, or keyboard. Initial A/B stripes
have equal whole-image brightness. Run performs nine calls: A, an independent
A repeat, and B for each seed 17, 29, 43. Copy A to B provides a same-image
control. Editors changing after a result visibly mark that result as the last
submitted input. Download JSON includes full precision and identities.

## Implemented boundary

- `flytrap/lab/contracts.py`: strict 256-byte A/B arrays, fixed seeds/work,
  bounded result contracts, provenance, sampling alignment, coverage and input
  consistency. `scripts/generate_lab_contracts.py` generates the AJV schema;
  `make check-lab-generated` detects drift.
- `flytrap/lab/sensory.py`: maintained extraction from the historical audit
  `artifacts/milestones/05/final-sensorimotor/retinal_coverage.py`. Its independent
  oracle reads checksum-verified raw annotations and derives sampling without
  consulting FlyEye's masks/UVs. It preserves upstream float32 arithmetic,
  truncation, clipping, missing-coordinate masks and stimulus encoding.
  Passive interception verifies the actual inference drive before brain.run
  and copies the pilot's unrounded population rates and existing statistics.
- `flytrap/lab/runner.py`: existing FlyController and explicit historical
  `fly-baseline-v1` checkpoint, all-one gains, learning off, `windowed_reset`,
  100 × 0.2 ms = 20 ms per sample. No navigation candidates or motor calibration
  are applied. Adapter, FlyEye and FlyBrain source files are unchanged.
- `flytrap/lab/api.py` and `budget.py`: one exclusive host file lock, computation
  in an isolated child outside the event loop, no queue or database. Request
  limit 8,192 bytes, result limit 2,000,000 bytes, 90 s wall deadline, child CPU
  limit 60 s and address-space limit 8 GiB; numerical threads fixed to one.
  Loopback binding, trusted local hosts, same-origin JSON POSTs, explicit
  409 busy / 503 unavailable / validation errors and no silent fallback.
- `web/src/Lab.tsx`, `lab-contracts.ts`, `lab.css`: one screen with exact grayscale
  inputs, coverage/discarded pixels, cyan L1 / orange L2 input drive on fixed
  0–180 / 0–108 Hz scales, and separately labeled neural output tables.
  Presets, brush, keyboard/touch editing, controls, sample SD, paired differences,
  raw rates/statistics, provenance, JSON download and stale-result/error states.
  Historical App remains available to the historical fixture profile and tests.

No inference is cached or auto-started. Each result states `cached: false` and
has a creation time; the server sends `Cache-Control: no-store`. Retained
results/screenshots in the review bundle are recorded evidence, not newly
executed inference. The UI cannot upload or replay arbitrary JSON.

## Measured result and limits

The real graph contains **165,122 neurons**. Each L1/L2 population drives
**1,767 cells**; 9 L1 and 12 L2 cells lack coordinates. Actual coverage is
**137/256 pixels**, leaving **119 discarded pixels**. Changing only discarded
pixels leaves the exact drive unchanged. This is an observed limitation of the
unchanged encoding, not a reason to reshape the retina.

Each comparison uses **n = 3 matched seeds**. Same-seed A repeats matched both
motor rates and existing statistics in all eight completed comparisons.
The same-image control matched A/B responses at each seed. Changing B to black
left A's corresponding response unchanged across independent API jobs.

All raw values are retained. For the browser's one-pixel vertical/horizontal
stripes, whole-image means are both 127.5/255. DNa02 L means were 116.6667 and
216.6667 Hz, with sample SD 115.4701 and 208.1666 Hz. Paired B−A differences were
400, 0 and −100 Hz; mean 100 Hz, sample SD 264.5751 Hz. The separately declared
two-pixel API stripes yielded paired differences 350, 100 and 0 Hz for that
population. These examples are input-dependent measurements with substantial
seed variation, not evidence of recognition or preference. Equal whole-image
brightness does not imply equal retinal drive because sampling discards pixels.

Motor rates are population-average spikes/s/neuron over 20 ms. `spike_count`
is the whole-graph spike total; `spikes_per_sec` is that total / 0.02 s;
`mean_mv` is final mean membrane voltage in mV. `firing`, `visual`, and `motor`
count distinct neurons active at least once during the window. Displayed
numbers round to four decimal places; JSON retains full precision. Matching
motor rates do not establish identical whole-brain activity. Perception,
preference, recognition, learning, biological vision and intelligence claims
remain unsupported and disabled.
