## Implemented boundary

[`graph.py`](../../../flytrap/data/graph.py) constructs a pure graph from explicit
tables, with sorted int64 bodies and allocation based on neuron count. Duplicate
directed counts sum before the default threshold of 3. Traced, non-Glia endpoints
survive. Missing/conflicting metadata, zeros, ties, malformed numbers and overflow
have explicit policies. Separate unsigned anatomical counts retain dopamine and
other zero-fast transmitters. Fast signaling remains float32 `W[post,pre]` with
upstream signs and scale. Incoming PAM/PPL1 count dominance is a documented
heuristic, not a biological-compartment or learning claim.

[`prepare.py`](../../../flytrap/data/prepare.py) and
[`bundle.py`](../../../flytrap/data/bundle.py) implement generation-pinned public
downloads, raw verification, Arrow batch reads, manifest publication and strict
round-trip loading. `data-fetch`, `data-build`, and `data-doctor` accept explicit
paths. Manifests record attribution, source checksums/versions, builder identity,
runtime versions, policy, observed statistics and ordered graph/metadata hashes.
Corrupt archives, pickle data, invalid sparse structures, altered signs/weights,
metadata or policy fail. Fixture bundles cannot satisfy the real-data gate.

The [data guide](../DATA.md) documents commands and policies. The default bundle
is `build/flytrap-v1/`, containing `graph.npz` and `manifest.json`.
`build_graph.py` delegates to this builder. Upstream `FlyBrain` loads the explicit
new graph path. Preparation never loads or promotes a checkpoint.

The public [MaleCNS download page](https://male-cns.janelia.org/download/) lists
the current `connectome-data/flat-connectome/` paths. The README's shorter prefix
returned HTTP 404. Corrected downloads verified provider MD5 and measured SHA256
before the [source catalog](../../../flytrap/data/sources.json) was pinned.
[Acquisition commands and metadata](../../../artifacts/milestones/02/acquisition/COMMANDS.md)
record the investigation and source schemas.

`make test-data-real` is separate from ordinary `make verify`, which explicitly
excludes `tests/real_data/`. Missing files fail; they never produce skipped
success. Playwright's output now follows `EVIDENCE`, preserving milestone 01
